Digital Privacy Guide

Every time you post photos, install mobile apps, or search online, you leave behind a digital footprint. Managing your privacy settings ensures strangers cannot misuse your personal photos, phone number, or location.

Key Privacy Concepts Every User Should Know

HTTPS Lock Icon
Indicates that data sent between your web browser and the website is encrypted so outsiders cannot read it.
Browser Cookies
Small files saved by websites; clearing third-party cookies limits unwanted online tracking.
Mobile App Permissions
Grant camera, microphone, or location access only to apps that genuinely require them.
Public Wi-Fi Safety
Avoid logging into sensitive financial accounts over open, unsecured Wi-Fi networks.

Risky Habits vs. Safe Privacy Habits

Daily Digital Privacy Comparison
Category Risky Habit (Avoid) Safe Habit (Recommended)
Social Media Keeping phone number and home address public Set profile visibility to Friends Only
Personal Documents Sharing ID card photos in open group chats Share sensitive documents only with verified recipients
Software Updates Ignoring browser and system security updates Install updates regularly to patch security flaws
